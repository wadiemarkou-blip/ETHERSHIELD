# Dépendances
L'archive contient des extraits minimaux compatibles avec les imports utilisés afin d'éviter les sous-modules vides du ZIP initial. Ce ne sont pas les distributions complètes des bibliothèques. Pour une version de production, utiliser les versions officielles épinglées : https://github.com/foundry-rs/forge-std et https://github.com/OpenZeppelin/openzeppelin-contracts.
